This is KScanUtils a desktop application with utility functions for scanning documents and merging, editing PDFs.

Core spec files:
- spec/mission.md: Mission of the application
- spec/tech-stack.md: Tech stack used
- spec/roadmap.md: List of features to be implemented -> populate and cleanup as you do development
- spec/risks/README.md: List of risks to be mitigated -> populate and cleanup as you do development each risk will have it's own file with details in that folder
- spec/usecases/README.md: A table of contents of the use cases
- spec/features/yyyy-mm-dd-feature-name: folder structure containing the plan.md, validation.md and requriements.md for each feature to be implemented.

Writing use cases:
- Use Cockburn style of writing effective use cases book
- Each use case might have multiple features
