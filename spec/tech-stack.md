# Tech Stack
Is a kotlin desktop application running on Windows, Mac and Linux
You use libraries with permissive licenses so that it can be used freely commercially.

## Libraries

- Compose Multiplatform for the desktop user interface.
- Apache PDFBox 3.0.8 (Apache License 2.0) for PDF parsing, merging, and output validation.
- Kotlin Coroutines for background PDF processing and Swing UI dispatch.
- Windows Image Acquisition (WIA) through the operating-system COM interface for Windows scanners.
- SANE's `scanimage` command for Linux scanners; it must be installed by the user or distribution.
