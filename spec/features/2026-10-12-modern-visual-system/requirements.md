# Modern Visual System — Requirements

## Purpose

Give KScanUtils a cohesive, contemporary desktop appearance without changing its workflows.

## Requirements

- **STYLE-1:** Screens use a consistent application color palette, typography scale, shape system, and spacing rhythm.
- **STYLE-2:** Content is presented on clearly separated surfaces over a subtle application background.
- **STYLE-3:** Page titles, section labels, descriptions, and actions have an unambiguous visual hierarchy.
- **STYLE-4:** Cards and drop targets provide clear default, focus, selected, and drag-active states.
- **STYLE-5:** The default and minimum window sizes keep the primary workflow usable.
- **STYLE-6:** Existing keyboard focus, accessibility semantics, and interaction behavior are preserved.
- **STYLE-7:** The application version is shown unobtrusively in the bottom-right corner on every screen.

## Out of Scope

- Dark theme and user-selectable appearance settings.
- Custom illustrations or branding assets.
