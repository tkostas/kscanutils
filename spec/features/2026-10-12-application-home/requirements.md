# Application Home — Requirements

## Purpose

Provide the starting point from which users discover and open KScanUtils utility categories.

## Requirements

- **HOME-1:** Starting the desktop application displays the home screen.
- **HOME-2:** The home screen presents available utility categories as cards.
- **HOME-3:** A **PDF Utilities** card is visible and can be opened with a pointer or keyboard.
- **HOME-4:** Cards have an accessible name and a clear selected, focused, and activated state.
- **HOME-5:** The home screen works on Windows, macOS, and Linux.

## Use-Case Traceability

Supports UC-1 steps 1-2 and extension 1a.

## Out of Scope

- The contents of a utility category.
- PDF file manipulation.
