# PDF List Ordering — Validation

| Requirement | Validation |
| --- | --- |
| ORDER-1 | Add three PDFs and verify insertion order. |
| ORDER-2 | Click and drag entries to the start, middle, and end; verify the row follows the pointer and settles in the new position. |
| ORDER-3 | Inspect and invoke the accessibility move-up and move-down actions. |
| ORDER-4 | Verify labels, positions, and accessibility semantics reflect every move. |
| ORDER-5 | Remove entries at each position and verify remaining relative order. |
| ORDER-6 | Add one file twice, move and remove one occurrence, and verify the other is unaffected. |
| ORDER-7 | Add enough files to overflow the available region; verify the scrollbar appears and merge controls remain visible. |
