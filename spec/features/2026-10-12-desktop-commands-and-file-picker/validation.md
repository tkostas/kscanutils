# Desktop Commands and File Picker — Validation

| Requirement | Validation |
| --- | --- |
| CMD-1 | Launch on each supported OS and verify File, Tools, and Help render consistently in the application header. |
| CMD-2 | Verify File contains only Exit and that Exit closes the application. |
| CMD-3 | Open Tools and verify Scan Documents opens UC-2; open Tools → PDF Utilities and verify its nested submenu contains Overview, Join PDFs, and Edit PDF Pages, then navigate with all three commands. |
| CMD-4 | Open About and verify the license appears below a horizontal divider, then dismiss the dialog. |
| CMD-5 | Select multiple PDFs in the native chooser and verify all are added. |
| CMD-6 | Add PDFs using the visible workspace button without dragging files. |
| CMD-7 | Hover File, Tools, Help, and PDF Utilities to verify each menu opens; repeat using clicks. |
| CMD-8 | Inspect menu padding and the boundary between Tools and PDF Utilities at supported display scales. |
| CMD-9 | From each non-home screen, activate the header brand by pointer and keyboard and verify Home opens. |
