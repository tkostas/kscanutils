# PDF Tool Navigation — Requirements

## Purpose

Allow a user to open PDF Utilities, select Join PDFs, and return to earlier screens.

## Requirements

- **NAV-1:** Opening the PDF Utilities card displays a screen of available PDF tools.
- **NAV-2:** The PDF tools screen includes an accessible **Join PDFs** tool.
- **NAV-3:** Opening Join PDFs displays its workspace and drop area.
- **NAV-4:** The user can navigate from Join PDFs back to PDF Utilities and from PDF Utilities back to Home.
- **NAV-5:** Screen titles and navigation controls clearly communicate the current location.

## Use-Case Traceability

Supports UC-1 steps 3-6.

## Out of Scope

- Adding files or performing a merge.
- PDF tools other than Join PDFs.
